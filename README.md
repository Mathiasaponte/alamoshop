# Álamos Identity Suite

LOGO PRINCIPAL Y SISTEMA VISUAL

I will provide a reference image that must be used as the primary brand logo for the entire product.

Use that uploaded image as the main visual identity reference across the platform.

Important:

treat the uploaded image as the official main logo for this product

use it consistently in the header, auth screens, splash/loading moments, favicon/app icon adaptation, and footer

preserve the overall institutional feel of the mark

keep the logo clean, centered, elegant, and recognizable

do not redesign it into something completely different

if simplified versions are needed for favicon, mobile nav, app icon, or compact UI, derive them from the same logo language

the logo should help the platform feel trustworthy, premium, school-community based, and organized

The product is still called Álamos Shop, but the uploaded logo should serve as the main identity anchor of the interface.

Visual use of the logo

Use the logo in these ways:

full logo in main header and landing page

compact emblem version where space is limited

monochrome or simplified version only when necessary for UI clarity

keep spacing generous around the logo

do not overdecorate it

do not distort or stretch it

maintain a premium institutional look



COLOR PALETTE

Use this exact brand direction for the UI.

Primary palette:

White — #FFFFFF

Off-white / soft white — #F7F5F1

Gray — #4B4F56

Gold — #C9A35A

Burgundy / guinda — #7B1023

Color behavior:

white and off-white should dominate the interface

gray should be used for typography, secondary UI, subtle structure, and neutral balance

burgundy / guinda should be the main brand accent and strongest identity color

gold should be used sparingly for premium details, small highlights, verified/premium moments, and refined emphasis

avoid making the interface too dark

avoid using bright random colors that break the brand language

do not overload the UI with gold

the overall feeling should be clean, elegant, premium, minimal, and trustworthy

Suggested usage

background: white / off-white

main text: gray

primary buttons: burgundy / guinda

hover states: deeper burgundy

badges or premium details: gold

borders/dividers: very soft gray

cards: white with subtle shadows

icons: gray or burgundy depending on emphasis



BRAND FEEL

The interface should feel like:

a modern startup

a private school community product

premium but not flashy

elegant but simple

safe and organized

youthful without looking childish

Design references:

minimal layout

lots of white space

refined typography

subtle premium accents

calm institutional confidence

The logo and palette should make the product feel more polished and more credible than a typical school project.
